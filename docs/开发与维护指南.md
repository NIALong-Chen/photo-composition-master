# 开发与维护指南

## 环境与构建

Android Studio 配置 SDK，安装 Platform 37.0、Build Tools 36.0.0、Platform Tools。工程使用 Wrapper 9.6.0、AGP 9.4.0；本地已验证 Studio 自带 JDK 25，Java 源码级别 17。首次构建需要网络下载依赖，仓库使用 Google Maven、Maven Central、Gradle Plugin Portal。

创建不提交的 local.properties：

```properties
sdk.dir=C:/Users/YOUR_USER/AppData/Local/Android/Sdk
```

```powershell
powershell -ExecutionPolicy Bypass -File .\build-debug.ps1 -JavaHome 'D:\Android studio\jbr'
```

输出 app/build/outputs/apk/debug/app-debug.apk，后续构建会覆盖。脚本只在当前进程设置 JDK；Wrapper 固定官方 ZIP SHA-256。

## 规则测试

在根目录执行，JDK bin 需位于当前终端 PATH，也可使用 javac/java 绝对路径。

```powershell
New-Item -ItemType Directory -Force build/rule-tests | Out-Null
javac -encoding UTF-8 -d build/rule-tests app/src/main/java/com/vinchen/photocomposition/CompositionGuide.java tests/CompositionGuideTest.java
java -cp build/rule-tests com.vinchen.photocomposition.CompositionGuideTest
```

预期 PASS: 26 composition and stability checks。规则测试不能替代真机验证。

## 安装验证

开启手机 USB 调试并授权，adb devices 状态为 device 后：

```powershell
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb shell dumpsys package com.vinchen.photocomposition
```

核对版本。新电脑默认 debug 签名可能不同，覆盖安装失败时不要直接卸载，以免丢失设置；持续分发前需安全管理统一签名材料，不上传私钥及密码。

最小回归包括竖横屏预览、人脸框与提示、开关、拍照不带叠层、查看返回、断网、无人/多人恢复。以根目录验收文档记录结果。

## 维护约定

- main 保存基线；功能或修复使用独立分支，验证后合并。
- 安装分发递增 versionCode；验证标签使用 v1.0.0-dev4 等明确后缀，正式通过验收前不标 v1.0.0。
- 功能变更同步技术文档、验收记录及 CHANGELOG。
- Issues 记录设备、版本、场景、复现、预期/实际表现与必要附件。
- 提交代码、文档、图标、Wrapper；APK 可作为后续 Release 附件，缓存、本机路径、照片、截图及密钥不提交。
- 暂未选择开源许可证，私有仓库不代表对外开源；正式发布前复核第三方依赖许可。历史参考项目若复用代码或模型，需要重新核对授权。
